# Foto Fight

A simple photo challenge game built with Expo (React Native).

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

## Running

- **Web**: `npm run web`
- **Android**: `npm run android`
- **iOS**: `npm run ios`

## Project Structure

```
app/
  _layout.tsx      # Root layout with navigation
  index.tsx        # Home screen with daily challenge
  camera.tsx       # Camera screen for taking photos
  leaderboard.tsx  # Leaderboard screen
```

## Tech Stack

- Expo ~51.0
- React Native
- Expo Router for navigation
- Expo Camera for photo capture
- TypeScript
